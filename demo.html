代理池与并发调度

智能负载均衡说明

当配置多个 HTTP/SOCKS 代理时，系统自动使用轮询机制将并发任务均衡分配到不同代理节点上，绕过上游 IP 频次限制并实现真正的多并发不排队。
若节点连续 5 次请求失败，系统将自动将其隔离并熔断，确保任务成功率。若代理池为空，系统将自动采用直连访问。

API 开发集成指南

1. OpenAI 格式兼容接口 (同步出图)

完全兼容 OpenAI /v1/images/generations 规范，无需修改代码逻辑，只需替换 Base URL 及 API Key 即可接入任何现有生态或工具（如 NextChat, LobeChat, Dify 等）。

# cURL 标准调用示例 curl -X POST "/v1/images/generations" \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk-your-key-here" \ -d '{ "model": "imagefree-v1", "prompt": "a majestic cyber dragon in clouds, neon lighting, ultra realistic", "size": "1024x1024" }'
# 官方 openai Python SDK 集成 from openai import OpenAI client = OpenAI( base_url="/v1", api_key="sk-your-key-here" ) response = client.images.generate( model="imagefree-v1", prompt="a cute cat astronaut floating in space", size="1024x1024", n=1 ) print(response.data[0].url)

2. 原生异步任务接口 (非阻塞)

适合大规模任务队列，提交后立即返回任务 ID，可通过轮询或 WebSocket 实时监听出图进度。

# 提交任务 POST "/api/generate" Headers: "Authorization: Bearer sk-..." Body: {"prompt": "...", "aspect_ratio": "16:9"} # 查询状态与进度 GET "/api/tasks/{task_id}"
